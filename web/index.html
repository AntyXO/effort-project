Start from your terminal

Use these commands in your own repository. Provider CLIs must be installed and signed in.

Using the downloaded source without a global install? Replace effort with node /absolute/path/to/effort-project/bin/effort.mjs.

1

Check your environment

See which local providers are available.

effort doctor
2

Preview a decision

Get a local recommendation from the command line.

effort recommend "Fix a race condition in the queue" --provider codex
3

Run with a verification command

Replace the repository path and choose a check for your project. This example allows the agent to write to that repository.

effort run "Fix the failing tests" --provider codex --cwd /path/to/repo --allow-write --verify '["node","--test"]' --max-attempts 3
4

Bring the advice to your desktop

Print manual MCP setup instructions for your app. Desktop integration is advisory; it does not control the app’s effort setting.

effort config codex
effort config claude
